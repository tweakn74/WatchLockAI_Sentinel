# CrowdStrike EDR Terminology and Concepts

## Core EDR Terminology

**Endpoint Detection & Response (EDR)**: An endpoint security solution that continuously monitors end-user devices to detect and respond to cyber threats like ransomware and malware.

**Endpoints**: Individual devices connected to a network that require monitoring and protection.

**Workloads**: Applications, services, or processes running on computing resources that need security oversight.

**Threat Intelligence**: Organized and analyzed information about potential or actual threats used to enhance detection capabilities.

**Behavioral Protection**: Security measures based on analyzing user and system behavior to detect anomalies and unknown threats.

**Network Containment**: The ability to isolate compromised endpoints to prevent lateral movement of threats.

## UI/Console Terminology

**Visibility**: The ability to see and understand events occurring within endpoints and the overall security environment.

**Incidents**: Security breaches or events that compromise system integrity or data, requiring investigation and response.

**Activities and Events**: Actions and occurrences on endpoints that are monitored, recorded, and analyzed for security purposes.

**Fast Response**: The capability to quickly act upon detected threats through automated or manual response actions.

## Key Operational Concepts

- **Continuous Monitoring**: EDR systems provide 24/7 surveillance of endpoint activities
- **Unknown Threat Detection**: Focus on identifying novel threats through intelligence features
- **Cloud-based Architecture**: Leveraging cloud infrastructure for scalable threat detection and response
- **Threat Database**: Repository of known threat signatures and patterns for comparison
