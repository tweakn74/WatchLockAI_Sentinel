# Glossary - WatchLockAI Sentinel Terms and Abbreviations

## Core System Terms

**Event Bus** - Central asynchronous message passing system that enables loose coupling between monitoring collectors and detection/response components. Implements publisher-subscriber pattern with weak references.

**Collector** - A monitoring module that observes system activity and generates typed events. Examples: fs_monitor, proc_monitor, reg_monitor, net_monitor, health_monitor.

**Detection Engine** - Component that processes events to identify potential security threats. Includes rules_engine, behavioral_engine, and threat_intel_db.

**Operational Mode** - System-wide configuration setting that controls monitoring behavior and response actions. Values: observe, alert, contain, quarantine, offline.

**RAG** - Retrieval-Augmented Generation. Knowledge system that combines search/retrieval with threat intelligence databases for contextual detection.

**Sentinel Event** - Base type for all system events generated by collectors. Includes FileEvent, ProcessEvent, RegistryEvent, NetworkEvent, HealthMetric, DetectionAlert.

## Technical Abbreviations

**API** - Application Programming Interface (REST API endpoints in console module)

**CRUD** - Create, Read, Update, Delete operations

**FQDN** - Fully Qualified Domain Name

**HTTP** - HyperText Transfer Protocol

**JSON** - JavaScript Object Notation (configuration and event serialization format)

**JSONL** - JSON Lines format (for event and alert logging)

**PID** - Process Identifier

**PPID** - Parent Process Identifier

**REST** - REpresentational State Transfer (API architecture)

**SaaS** - Software as a Service

**TI** - Threat Intelligence

**TTL** - Time To Live

**UUID** - Universally Unique Identifier

**YAML** - YAML Ain't Markup Language (primary configuration format)

## Security and Detection Terms

**Alert** - A detection event that indicates potential security threat, generated by detection engines

**Behavioral Analysis** - Detection technique that identifies anomalous patterns in system activity over time

**C2** - Command and Control (malware communication channel)

**EDR** - Endpoint Detection and Response

**IOC** - Indicator of Compromise

**Kill Chain** - Attack methodology framework (e.g., Lockheed Martin Cyber Kill Chain)

**MITRE ATT&CK** - Framework for categorizing adversary tactics, techniques, and procedures

**Provenance** - Information about the source and lineage of detection rules or alerts

**Quarantine** - Isolation of suspicious files or processes to prevent further system damage

**Rules Engine** - Component that applies security rules to events to generate alerts

**Threat Hunting** - Proactive searching for threats using intelligence and behavioral indicators

**TTP** - Tactics, Techniques, and Procedures (adversary behavior patterns)

## Windows-Specific Terms

**HKCU** - HKEY_CURRENT_USER (Windows registry hive)

**HKLM** - HKEY_LOCAL_MACHINE (Windows registry hive)

**Registry** - Windows system database storing configuration information

**Service** - Windows background process that runs without user interaction

**WinAPI** - Windows Application Programming Interface

**pywin32** - Python library for accessing Windows APIs

## Configuration and Storage Terms

**Atomic Write** - File operation that ensures data integrity by writing to temporary file then renaming

**Config Guard** - Code pattern that validates configuration values and provides safe defaults

**Environment Override** - Configuration value specified via environment variable (SENTINEL_* prefix)

**Operational Mode Storage** - Persistent JSON file storing current operational mode state

**Pydantic Model** - Python class using Pydantic library for data validation and serialization

## Monitoring and Events Terms

**Burst Window** - Time interval used to group related file system events for analysis

**Event History** - Circular buffer maintaining recent events for replay and analysis

**Event Subscription** - Registration of a component to receive specific types of events from the bus

**Health Metric** - System resource usage measurement (CPU, memory, disk, temperature)

**Monitor Polling** - Regular checking of system state at defined intervals

**Platform Guard** - Code pattern that enables/disables functionality based on operating system

**Weak Reference** - Python reference that doesn't prevent garbage collection of the referenced object

## Response and Actions Terms

**Actions Manager** - Component responsible for executing response actions (process termination, quarantine, etc.)

**Destructive Action** - Response action that modifies or deletes system resources (requires explicit authorization)

**Monitoring Pause** - Temporary suspension of monitoring activities for specified duration

**Process Termination** - Response action that kills a running process identified as malicious

**Response Action** - Automated remediation step taken in response to detected threats

## Web Console and API Terms

**Dashboard** - Main web interface showing system status and recent activity

**FastAPI** - Python web framework used for REST API implementation

**OpenAPI** - Specification for REST API documentation (formerly Swagger)

**Template** - Jinja2 HTML template for web console pages

**Uvicorn** - ASGI server used to run FastAPI application

**Web Console** - Browser-based interface for monitoring and managing Sentinel

## Development and Architecture Terms

**Async/Await** - Python asynchronous programming pattern used throughout the system

**Circular Import** - Python import dependency cycle (avoided using lazy imports)

**Event-Driven Architecture** - Design pattern where components communicate via events rather than direct calls

**Import Guard** - Code pattern that handles optional dependencies gracefully

**Lazy Import** - Importing modules inside functions rather than at module level to avoid circular dependencies

**Modular Architecture** - Design approach where functionality is separated into independent, interchangeable components

**Publisher-Subscriber** - Messaging pattern where publishers send messages to subscribers without direct coupling

**Type Annotation** - Python syntax for specifying variable and function parameter types

**Type Safety** - Programming approach that prevents type-related errors through static analysis

## File and System Terms

**Entropy** - Shannon entropy measurement of file randomness (used for detecting encrypted/compressed files)

**File Hash** - Cryptographic fingerprint (SHA256) of file contents for integrity verification

**Glob Pattern** - File path pattern using wildcards (* and **) for matching multiple files

**JSONL Logging** - Structured logging format where each log entry is a separate JSON object

**Path Normalization** - Converting file paths to standard format for consistent processing

**System Metrics** - Quantitative measurements of system resource usage and performance

**Watchdog** - Python library for monitoring file system events across platforms
